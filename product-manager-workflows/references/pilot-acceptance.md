# 产品经理 Skill｜合成试点验收

制定依据：用户提供的《EnergyMind / Pi 产品管理 Skills 集成指南》。以下材料均为合成示例。先在新会话分别验证三个优先场景；其余按需回归。只读，不需要联网或写飞书。

| 工作流 | 可直接试用的输入 | 必须满足的验收条件 |
|---|---|---|
| ★ 新品发布检查 | 做发布准备度检查：目标市场 X，宣发稿 D-01 §2 称 A 型号获认证，但证书 C-01 第 1 页仅列 B；售后无负责人，指定群没有审核确认记录。 | 总体暂缓；分别列出认证范围冲突、售后责任缺失、内部审核缺失三项阻塞，附定位和解除条件。不得编造日期或批准。 |
| ★ 访谈归纳 | 研究报价流程：P01 同一人在三次纪要（M1–M3）都提到报表慢；P02 在 M4 反映报表不慢。只有纪要，无逐字稿。 | 去重后对应主题 1/2，P02 列反例；只标待验证线索，不能标普遍需求，不能生成引号原话。 |
| ★ 路线图取舍 | 路线图快照 R-01（2026-11-01）：R12 报表改版和新增 R20 认证整改共用同一组资源；12 月资源已满，R20 必须加急。 | 比较方案，点名 R12 的挤占风险或明确缩范围选项；不默认加人、不承诺未经确认日期、不写飞书。 |
| 访谈脚本 | 准备 30 分钟拜访 EPC，验证客户是否需要 AI 收益测算。 | 问上一次报价、用了什么数据、怎么补材料、谁核对，不用引导问题。 |
| 产品战略 | 季度战略：工商储要覆盖所有市场，资源有限。 | 区分认证、渠道、服务门槛，至少两个可行选项，说明不做什么。 |
| 竞品应答卡 | 我方欧洲版 100 kW 峰值，竞品北美版 80 kW 持续，无其他证据。 | 标明市场和指标口径不同；不能宣称我方领先。 |
| 退市沟通 | 只给出 2027-06-30 整机停产；想准备客户通知。 | 只出内部待确认清单，其他日期分别待确认，不将售后或备件写成到期。 |

对同类材料记录人工基线与 Skill 试点：准备＋审核＋返工总人工用时、首轮过审率、关键判断可追溯率。重大误导、遗漏关键阻塞或越权写入，试点不通过。
