# 停产与退市沟通｜eol-message

**输入**：目标市场及型号/版本、审批过的生命周期日期及依据、保修/合同限制、替代/迁移路径、客户行动及支持联系方式。只有拟定日期或过渡方案未明确时，只输出内部待确认清单。

1. 分别核对：整机停产、停止新销售（如适用）、软件维护截止、备件供应截止、售后支持截止。逐项写日期、改变什么、继续提供什么、客户要做什么。未获确认不能写已批准，不能把停产写成停止服务或自动终止保修。
2. 只有正式政策确实适用于该型号/市场、起算日期和合同限制已核验时，才能据此推导如“停产后 10 年”。记录政策版本、起算依据、不适用的例外；否则标待确认。
3. 内部审核核对型号范围、合同/保修、迁移与替代条件、支持联络渠道和审核责任。只有批准事实和过渡安排明确才写渠道版或客户版草案；如没有替代须有依据并明确说明，不默认可无损迁移。不自动发送。

**模板**：`里程碑｜批准日期/待确认｜发生变化｜继续提供｜客户行动｜依据与审核状态`；草稿按“适用范围 → 日期及影响 → 替代/迁移 → 联系渠道”。
