# 访谈证据归纳｜discover-interview-synthesis

**输入**：研究问题、脱敏访谈或反馈记录、独立受访者 ID、角色／市场；可补日期、项目阶段及样本选择方式。如果独立性无法判断，标明去重不确定，不把记录条数当人数。

1. 为本轮确定纳入样本及分母。若并非所有人都被问到同一题，可以另列该题实际覆盖人数，解释两种分母。未被问到不等于不同意，同一人跨场重复只算一人。
2. 先摘客户原话或观察，再按问题、发生情境和后果聚类。仅逐字记录可作带引号的原话；会议摘要标“转述”。把客户提出的解决方案与背后任务/痛点分开。
3. 每个主题列支持人数及分母、反例、来自哪些角色或市场、样本局限。至少 3 名独立受访者有直接证据支持，才标“本样本复现主题”；不足标“待验证线索”或“单客户要求”。出现次数不代表严重程度或市场代表性。
4. 给出信心及原因（证据直接性、样本覆盖、一致性），写下一步要验证什么、找谁、用什么证据；单场可输出案例卡。需要转路线图时保留同一证据 ID，不把线索直接当需求立项。

**模板**：结论＋样本口径；`主题 ID｜问题与情境｜支持人数/分母｜原话/观察及位置｜反例/局限｜解释与信心｜下一步验证`。单客户的明确诉求单列；没有证据的建议标假设。
