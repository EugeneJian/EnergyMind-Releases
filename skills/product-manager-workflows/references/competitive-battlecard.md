# 竞品应答卡｜competitive-battlecard

**输入**：双方完整型号、目标市场、客户场景、来源材料与核验日期；按需记录硬件/固件、附件配置、测试条件。缺其中关键字段就标待确认，不做确定性比较。

1. 先判逐项可比性。标称/可用容量、持续/峰值功率、测试温度与配置分开；不能用欧洲版或北美版的不同市场证书代替目标市场覆盖。口径不一致时写不可比，不宣称领先。
2. 原厂规格、第三方实测和未核验反馈分列。只有授权搜索可用且有必要时使用，优先官方公开资料；离线只用输入快照，未核验则标明，不冒称最新。
3. 分列我方与对手各自有证据的优势、适用情境和不确定项。给最多三个关键异议应答；对客版不引用内部资料或无证据的贬损，不当成正式参数承诺。

**模板**：`维度｜我方｜对方｜市场/型号/测试口径｜来源位置｜核验日期｜可比/待核验/不可比`；另列“可对客回应”与“仅内部参考、暂不能对外讲”。
