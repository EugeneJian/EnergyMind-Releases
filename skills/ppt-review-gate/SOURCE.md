# `ppt-review-gate` 来源记录

- **方法参考**：[Hermess/ppt-director](https://github.com/Hermess/ppt-director)，核对版本 [`afed50277541999ed768d8ce0e1f2fb8d3e0e313`](https://github.com/Hermess/ppt-director/tree/afed50277541999ed768d8ce0e1f2fb8d3e0e313)。核对日期：2026-11-22。
- **发现渠道**：[知乎《8个神级PPT Skills, 开源了！》](https://zhuanlan.zhihu.com/p/2065851049177622295)。知乎文章为推荐入口，GitHub 仓库为方法参考来源。
- **许可与复用边界**：在所查版本未发现明确许可证。本技能是独立编写的 EnergyMind 工作流，只参考「先策划、再预审、最后出稿」的通用方法；未复制上游提示词、模板、图像、评审卡或脚本，不是上游的移植版，也不需要安装上游仓库。
- **本地取舍**：以受众决策、逐页结论与证据、关键页预审为核心；不强制 HTML 预览，不部署到外部服务。需要可编辑的本地 PowerPoint 时，使用现有 `pptx-builder` 和已获授权的母版。
