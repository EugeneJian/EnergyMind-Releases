# EnergyMind 团队技能

技能本身放在仓库的 `skills/<skill-name>/`，目录中应包含 `SKILL.md`。本目录决定发布哪些技能：每发布一个技能，就在这里创建一个同名的 Git 符号链接，指向 `../skills/<skill-name>`。例如 `pptx-builder` 指向 `../skills/pptx-builder`。

在 EnergyMind 中开启「从 GitHub 同步团队技能」后，应用从本目录发现团队技能（单向同步，本机只读）。技能放在 `skills/` 子目录需要 5.2.23 及以上版本；5.2.22 及更早版本只接受指向仓库根目录的链接，同步失败时继续使用上一次成功同步的版本。

更新 `skills/` 下的文件即可发布新内容。删除对应链接可将该技能移出发布，已安装的团队技能随下次同步移除。
